入库报错，先找是哪一行

例如数量列本应是整数，业务表格里却混入了「待定」。

  1. 提供 PostgreSQL 或 SQL Server 的表结构，再导入待验数据。
  2. 确认源字段与目标字段的映射，运行逐行校验。
  3. 按错误类型筛选明细，从字段和实际值回查原始记录。

常见问题

SQL 脚本和业务文件会到哪里？

文件处理在本机完成。生成的脚本由你复制或保存，再到数据库客户端执行。在线画板会通过 WebView2 加载 Excalidraw，更新检查读取公开版本清单，可在设置中关闭。

手上的数据该用哪个建表工具？

手上是 Excel、CSV 或 DBF 时，用「临时数据建表」生成建表和插入脚本，列按字符串处理。手上已有 INSERT，或希望自行调整字段类型时，用「快速建数据表」。查看支持的数据库和格式

导入前能查出哪些错误？

规则以目标字段为单位，检查类型、格式和部分结构约束，例如整数格式和必填项。跨字段关系、外键存在性等业务要求需要另外核查。查看完整校验规则 ↗

换电脑时怎么带走设置和便签？

把 EXE 同目录下的 settings.json、invoice_templates.json 和 invoice_print_history.json 一起复制过去。便签正文位于 %LOCALAPPDATA%\CCToolbox\quick-notes.txt。

如何手动检查更新？

在「系统参数配置 → 软件更新」选择「立即检查」。发现新版后，程序会提示并提供下载页，你可以自行下载新版 EXE。离线时也可在设置里选择本地更新清单。

在线画板和发票打印各需要什么？

画板需要 WebView2 Runtime 和访问 Excalidraw 的网络。发票预览与打印支持 PDF 和图片，OFD 目前可以登记。

Windows 提示无法验证发布者怎么办？

目前发布的 EXE 未做数字签名。你可以核对 Releases 提供的校验信息，或按 GitHub README 的命令从源码构建。
