01 / 为什么

少一些重复操作，多一些清晰结果

实施现场的麻烦通常不是「不会做」，而是同一件事要反复手工确认。这个工具把几个高频环节收在一起，并且让每一步的结果都能拿出来复核。

表格转 SQL 不再手工拼

导入 Excel / CSV / DBF，预览并修正内容后生成建表与批量 INSERT 脚本；四类数据库的标识符、临时表与批量语法自动适配。

导入报错能定位到行

按目标表结构建立字段映射，逐行检查类型与格式约束，把问题落到行号、字段和实际值，并导出带主键定位信息的 Excel 报告。

前后差异一眼看全

CSV 按行号或复合主键对比，JSON 按结构对比；新增、删除、修改与类型变化分类呈现，支持筛选与导出。

深层 JSON 不靠肉眼

格式化、压缩、语法校验，配上可折叠的嵌套表格浏览与编辑回写，让多层对象与数组在保留上下文的前提下查看和修改。

零散小事一个入口

发票排版打印、在线画板、随手记与系统参数配置都在同一套导航里，减少来回找工具和重复设置。

结果能带走

SQL 可以复制或保存为 .sql，数据与报告可导出 CSV / JSON / Excel；导出统一使用带 BOM 的 UTF-8，Excel 打开中文不乱码。

左侧导航按「数据工具 / 开发工具 / 办公工具 / 系统」分组；CSV 对比藏在系统参数配置的实用小工具里。

04 / 边界

能做什么，不能做什么，都写清楚

下面是当前版本真实的限制。把它放在官网，比放在用户踩坑之后更好。

不直连数据库SQL 只生成、不执行；字段校验也基于文本与文件，脚本由你在数据库客户端运行。
校验范围有限目前仅支持 SQL Server / PostgreSQL，覆盖类型与格式约束，不校验业务语义、跨字段关系、外键存在性与 JSON Schema。
建表列全是字符串「临时数据建表」把所有列按字符串输出，依赖目标库隐式转换；需要精确类型请用「快速建数据表」。
OFD 尚未渲染可以选择登记，但预览与打印为空，请使用 PDF 或图片。
画板依赖外网在线绘图通过 WebView2 加载 Excalidraw，需要 WebView2 Runtime 与网络连接。
配置写在程序目录settings.json 等文件在 exe 同目录，放到只读安装位置会保存失败。
部分状态不持久CSV 对比的页面状态只在进程内存，退出程序即丢失。
大文件有阈值超过 10 万行生成前会确认；SQL 超过 5000 行时只预览前 1000 行（复制与保存仍完整）；校验明细上限 1 万条。
exe 未签名可能被 SmartScreen 或杀软启发式误报，可核对 Releases 校验信息或从源码自行构建。

完整技术说明见仓库内「程序说明」；校验规则、在线更新方案均以 Markdown 形式随源码提供。

05 / 问答

你可能想问的

需要安装 .NET 或 VC++ 运行库吗？

不需要。发布包是自包含单文件 exe，依赖已打进程序；只有从源码调试运行才需要 .NET 10 SDK。在线画板另需系统已安装 WebView2 Runtime。

会上传或收集我的数据吗？

核心功能（表格转换、CSV 预览与对比、JSON 处理、数据校验、发票打印）全部在本机内存完成，不连数据库、不上传文件。联网点只有两个：「在线绘图工具」通过 WebView2 加载 excalidraw.com，以及「检查更新」读取公开的 latest.json 清单（不上传任何数据，可在设置页关闭）。

支持哪些数据库？

建表与 INSERT 脚本生成支持 PostgreSQL、SQL Server、MySQL、Oracle 四种；「数据验证排查」目前只支持 SQL Server 与 PostgreSQL。

支持哪些文件格式？

表格导入支持 .xlsx .xls .csv .dbf；分隔文本预览与对比支持 .csv .tsv .txt .dbf .bdf；发票支持 PDF 与 JPG / PNG / BMP / TIF，OFD 除外。

配置文件在哪里？换电脑怎么办？

settings.json、invoice_templates.json、invoice_print_history.json 写在 exe 同目录；随手记在 %LOCALAPPDATA%\CCToolbox\quick-notes.txt。换机时连同这几个文件一起拷贝即可。

杀毒软件或 SmartScreen 报毒怎么办？

当前 exe 未做数字签名，加上需要读写文件与操作剪贴板，容易被启发式规则误判。可以核对 Releases 页面的校验信息、把文件加入信任，或直接按仓库 README 的命令从源码构建。

怎么检查更新？程序会自动升级吗？

到「系统参数配置 → 软件更新」点「立即检查」；程序启动时也会静默检查一次（可关闭）。发现新版本后只提示并打开 GitHub Releases 下载页，不会自动下载或替换文件。无公网时可在设置里点「选择本地清单」，或把更新源改成共享目录中的 latest.json。

画板打不开？

请确认系统已安装 WebView2 Runtime 且能访问 excalidraw.com。其余核心功能离线可用；除画板外只有检查更新会联网，且可关闭。

GitHub 下载太慢或打不开怎么办？

用「下载」区的国内备用地址（蓝奏云）：打开国内下载，页面提示输入提取码时填 dvqy，下载卡上也有一键复制按钮。镜像由第三方网盘托管，版本可能晚于 Releases 同步；想确认是否为最新版，请对照 GitHub Releases 的版本号。
